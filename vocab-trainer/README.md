# 考研英语一 · 极速刷词（1829 条）

手机优先的单文件离线刷词工具。源文件为 [index.html](./index.html)，内置 1,829 条熟词生义与核心搭配，每条都有中文释义、英文例句和例句中文翻译，无需后端或登录。

## 使用

- 在浏览器中打开本目录的 `index.html`；如果 GitHub Pages 已从 `main` 分支部署，网页地址通常是 https://yy4550.github.io/vocab-trainer/ 。
- 每组 7 条；点击词条释义区域可显示或隐藏中文。
- 左滑收藏、右滑标记简单；右侧箭头进入详情页查看双语例句。
- 支持顺序 / 乱序两种模式、上一组 / 下一组切换。
- 收藏词、简单词可在各自列表查看与撤销。标记简单的词会被普通刷词流程跳过。
- 进度与分类记录保存在当前浏览器的本地存储中；可通过应用设置导出 / 导入备份。

## 数据与注意事项

- 所有学习内容和界面代码均包含在单个 HTML 文件中。
- 本地打开的 `file://` 版本与 GitHub Pages 上的版本通常不共享浏览器存储，切换访问方式前建议导出备份。
- 不同浏览器和不同设备之间不会自动同步进度。
- 原词表没有音标字段；此版未添加音标或语音功能。
